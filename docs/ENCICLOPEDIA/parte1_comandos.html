Palabras Mágicas Activas מילות כוח — Milot Kóaj

Comandos funcionales del Propietario · 11 palabras de poder

Di cualquiera de estas palabras a Copilot y ejecutará la acción inmediatamente, sin preguntar.
Son atajos de alto nivel que disparan workflows completos. — Protocolo Milot Kóaj, Proyecto Golem
1 · crece ACTIVA
גדל — Gadál — "Crecer"
Robustecimiento + Equilibrio del Etz HaChaim. Copilot ejecuta un ciclo Tikún Jai completo (NIGREDO→RUBEDO) enfocado en: auditar balance de Sefirot en SDD §4.17.2, proponer RFs que equilibren el Árbol, revisar y mejorar DEVELOPMENT_WORKFLOW.md, revisar coherencia SRS↔SDD↔código.
CRECIMIENTO ORGÁNICO: no agregar features nuevas sino robustecer la infraestructura existente. Pipeline E.
2 · tikún ACTIVA
תיקון — "Reparación"
Ciclo de mejora estándar. Ejecutar Tikún Jai completo (Regla #17) con todas sus fases: NIGREDO→ALBEDO→CITRINITAS→Gate 2→RUBEDO→PALINGENESIA.
Busca problemas, investiga, propone, implementa. El corazón del desarrollo.
3 · status ACTIVA
מצב — Matsáv — "Estado"
Reporte rápido del estado. Lee WorkItems.md + grep de tests + último commit. Reporta: (1) WIs pendientes, (2) Tests PASS/FAIL, (3) Último cambio, (4) Balance general de Sefirot.
Formato compacto, máximo 20 líneas.
4 · limpia ACTIVA
טהר — Tahér — "Purificar"
Limpieza de deuda técnica. Pipeline C focalizado: código muerto / imports sin usar, tests sin assertions, TODOs/FIXMEs olvidados, archivos huérfanos en datos/, sesiones memory obsoletas.
Proponer eliminaciones como WorkItems atómicos.
5 · protege ACTIVA
שמור — Shmór — "Guardar/Proteger"
Auditoría de seguridad. Ejecutar D7 (Legal & Seguridad): revisar SECURITY_PLAN.md vs estado actual, OWASP check, verificar secrets, evaluar dependencias con CVEs.
El escudo de Gevurá del proyecto.
6 · enseña ACTIVA
למד — Laméd — "Aprender/Enseñar"
Explicación profunda. Copilot explica en detalle el tema que sigue a la palabra. Ej: "enseña NLU" → explicación de la arquitectura de 3 niveles del cerebro.
Modo profesor, no implementador.
7 · empuja ACTIVA
דחוף — Djóf — "Empujar"
Git commit + push. Copilot hace: git status → git add -A → genera mensaje de commit → git commit → git push. Pide confirmación del mensaje ANTES de push.
El impulso que manda tu trabajo al mundo.
8 · despierta ACTIVA
התעורר — Hit'orér — "Despertarse"
Iniciar Golem. Ejecutar python -m golem en terminal background. Verificar que arranca sin errores.
El aliento que da vida al Golem. Emet (אמת) en su frente.
9 · duerme ACTIVA
ישן — Yashán — "Dormir"
Detener Golem. Terminar proceso de Golem gracefully.
Shabat digital — descanso sagrado que permite la renovación.
10 · crece automáticamente ACTIVA
גדל מאליו — Gadál Me'eláv — "Crecer por sí mismo"
Robustecimiento autónomo continuo. Igual que "crece" pero con ejecución autónoma: Copilot encadena ciclos Tikún Jai sin intervención. Gates pre-aprobadas (Gevurá relajada). Límite de 5 ciclos antes de presentar resumen al Propietario.
Se detiene cuando: (1) no hay hallazgos ≥ MEDIA, (2) 5 ciclos sin validación, (3) "basta".
11 · fluye ACTIVA
שטוף — Shtóf — "Fluir"
Releer workflow completo. Copilot relee DEVELOPMENT_WORKFLOW.md completo de principio a fin, recargando todas las reglas, Palabras Mágicas, Sefirot, protocolos y flujos.
Usar cuando el contexto se siente desfasado o al inicio de sesiones largas.

♦⊕☿ Tria Prima — Gramática Formal de Comandos

Los 19 Milot Kóaj se invocan con solo 3 palabras fundamentales (Chomsky Tipo 2).

♦ amén Azufre — Voluntad · Fuego Afirma, aprueba, ejecuta. Gates pre-aprobadas.
⊕ por favor Sal — Materia · Tierra Solicita, pide, invoca con cortesía.
☿ gracias Mercurio — Espíritu · Aire Cierra ciclo, agradece, disuelve con gracia.
♦♦♦ Invocación Ritual

amén, amén, amén. — (literal exacto, minúsculas, acentos, comas, punto final)

Dispara meta-análisis recursivo: Tikún del Tikún. El sistema audita sus propias reglas.

Reglas de las Palabras Mágicas

  • Se pueden combinar: "crece y empuja" = robustecer + commit+push al final.
  • Si la palabra va seguida de contexto, usarlo: "tikún voz" = Tikún enfocado en módulos de voz.
  • "por favor" + PM = petición cortés (Gevurá activa, puede preguntar en Gates).
  • PM + "amén" = ejecución autónoma (Gevurá relajada, gates pre-aprobadas).
  • PM + "gracias" = ejecutar + cerrar ciclo al terminar.
  • "gracias" en medio de un ciclo = detener con nota positiva.
  • Las palabras mágicas NO eximen de las Reglas Anti-Colateral.
  • Nuevas palabras se agregan con aprobación del Propietario (Gate 2).
  • Las sugerencias se registran en PALABRAS_MAGICAS_SUGERENCIAS.md.
