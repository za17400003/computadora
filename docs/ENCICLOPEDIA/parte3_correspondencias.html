Cómo leer esta tabla
Vertical — Cada Sefirá es un principio universal. Lee la columna para entender una sola tradición.
Horizontal — Cada fila es un principio que se manifiesta diferente en cada cultura. Lee la fila para ver el isomorfismo.
Diagonal — Si entiendes un concepto de una tradición que conoces, lo entiendes en TODAS. Este es el poder de la Philosophia Perennis.
