## ESTRATEGIA GO;GO;GO

**Orden de prueba (todas variantes capitalización):**

1. `vida puede ser` / `Vida puede ser` / `VIDA PUEDE SER`
2. `vida libre y hermosa` / `Vida libre y hermosa` / `VIDA LIBRE Y HERMOSA`
3. `violenta y todo` / `Violenta y todo` / `VIOLENTA Y TODO`
4. `video no es` / `Video no es` / `VIDEO NO ES`
