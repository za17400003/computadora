## APRENDIZAJES PRINCIPALES (Lo Más Importante)

### 1. "Fantasma" es Peor que "Abandonado"

```
Fantasma (antes):   "¿Qué es Minimi? ¿Existe?"   ← MISTERIO
Abandonado (ahora): "Minimi fue Feature, se paró" ← TRANSPARENCIA
```

Documentar abandono = mejor que dejar hueco de memoria.

### 2. Axioma III.7 Exige Ciclo E Completo (incluso de abandonos)

```
Feature Mayor debe tener:
NIGREDO: Qué fue
ALBEDO:  Por qué se paró
CITRINITAS: Qué aprendimos
RUBEDO: Código/Doc actualizado
PALINGENESIA: Lecciones registradas

Esto incluye Feature que fue COMPLETAMENTE ABANDONADA.
```

Minimi ahora tiene ciclo E retroactivo (WI-291).

### 3. Testing Asincrónico Requiere Patrones Especiales

```
❌ INCORRECTO: motor = MotorProactividad()  # QThread corre en background
✅ CORRECTO:   monkeypatch.setattr(motor, 'run', lambda: None)
```

Pattern establecido para reusar en FP-142+.

### 4. Sinceridad es Escalable

```
En inicio: "Minimi no existe" ← fácil
En medio: "Minimi existe pero..."
En fin: "Minimi fue intentado y abandonado — aquí es por qué" ← difícil pero correcto
```

Verdad completa > verdad cómoda.
